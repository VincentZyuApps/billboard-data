# 2026-10-09 Billboard-Data 双源扩展规划与实施方案 (Niconico VOCALOID SONGS TOP20)

## 1. 架构目标
- 将原有的单一《Bili Board 术力口周榜》(UID: 3546800279522160) 扩展为多源架构：
  - **Bilibili 数据源**：由 Bili Board Atel 周榜公开专栏提供，覆盖 B 站本土术力口周榜。
  - **Niconico 数据源**：由秋叶-风 (UID: 12446725) 专栏提供，同步收录日本 Billboard JAPAN 与 ニコニコ 官方合作出品的《ニコニコ VOCALOID SONGS TOP20》。
- 实施彻底的分组解耦架构（Breaking Change）：`data/bilibili/` 与 `data/niconico/`。
- 规范化文件命名模式：`issue_{issue}_{date}.json`。

## 2. 爬虫改造详情
- 废弃原单一 `scripts/crawler.py`，拆分为两个职责明确的专用爬虫：
  - `scripts/crawler_bilibili.py`：负责增量/全量抓取 B 站周榜与视频元数据。
  - `scripts/crawler_niconico.py`：负责解析 Niconico TOP20 专栏文本（排名、曲名、P主、在榜周数、上一周排位）并提取关联的 B 站站内视频 `aid`，批量补全 `bvid`、高清封面 `pic_url` 及 UP 主信息。
- GitHub Actions CI 工作流 (`.github/workflows/crawl-weekly.yml`) 针对 N 站发布时间设计了周三 19:00 至 20:30 每 10 分钟一次的高密定时轮询机制，有更新时自动生成标准 Bot Commit。

## 3. Koishi 插件扩展规划 (`koishi-plugin-billboard-data`)
- **配置项扩展**：
  - `defaultSource`: `'bilibili' | 'niconico'`（默认 `'bilibili'`，单选）。
  - `broadcastTargets`: 广播表格中增加 `sources: ('bilibili' | 'niconico')[]` 多选字段（默认双选）。
- **指令扩展**：
  - `周榜` / `bb`：主指令支持 `-s, --source <source>` 选项，未指定时强制读取 `config.defaultSource`。
  - `周榜b`：别名指令，快捷路由至 `bb -s bilibili`。
  - `周榜n` / `nb`：别名指令，快捷路由至 `bb -s niconico`。
  - `周榜.查歌` / `bb.search`：支持在指定源或默认源中检索歌曲榜单战绩。
- **渲染器适配**：
  - Takumi / Puppeteer 模板针对 N 站周榜（第 1~20 名）标题、副标题、P主（Author）以及在榜周数、上期排名等特殊字段自适应排版。
